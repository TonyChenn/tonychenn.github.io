Runtime Editor for Cocos2d-x

CocosEditor

为 Cocos2d-x 打造的运行时编辑器

检查、编辑、调试。
直接在正在运行的游戏中完成。

CocosEditor 是面向 Cocos2d-x 项目的运行时编辑与调试工具。无需反复修改代码、编译和重启游戏，即可实时调整 UI 并定位运行时问题。

01 / Live Hierarchy

查看实时场景节点树

浏览正在运行的游戏中实际存在的节点层级。

快速找到 UI 节点，查看父子关系，定位层级嵌套和绘制顺序问题。直接查看当前的 Cocos2d-x 节点树，不必仅凭代码推断运行状态。

在 Game 或 Hierarchy 中选择节点，即可在 Inspector 中检查同一个对象。

02 / Runtime Inspector

实时检查与修改属性

选中节点后，在游戏运行中查看或修改受支持的组件属性。

通过 Cocos2d-x Inspector 调整已开放的位置、尺寸、缩放、可见性、颜色和文字等属性。受支持的修改直接作用于实时节点，并反映在 Game 画面中。

无需重新编译。无需重启游戏。即时反馈。
Inspector → Game修改受支持的数值，在上方实时 Game 画面中观察所选节点的变化。

运行时修改作用于当前会话，不会自动保存到源码或 CSB/CSD 文件。

FAQ / 常见问题

连接前，先了解这些。

实时查看游戏，同时明确运行时修改与项目文件的边界。

CocosEditor 是什么？

CocosEditor 是面向 Cocos2d-x 的运行时编辑与调试工具。连接已接入 SDK 的游戏后，可以查看实时节点树、修改受支持的组件属性、浏览资源、查看日志，并通过 MCP 开放受支持的运行时能力。

CocosEditor 会修改我的 Cocos2d-x 项目吗？

首次接入 Runtime SDK 需要调整原生工程配置，并接入启动与退出生命周期。连接后，Hierarchy 与 Inspector 操作的是运行中的游戏状态；运行时属性修改不会自动重写项目源码或场景资源文件。

是否需要接入 SDK？

需要。游戏必须接入对应目标平台的 CocosEditor Runtime SDK，且版本与编辑器匹配。C++ 和 Lua 项目都需要完成这一步。

运行时修改可以保存回项目吗？

运行时修改不会自动回写 Cocos2d-x 项目源码、CSB、CSD 或其他场景资源。Inspector 中的修改应视为当前运行会话的状态调整。如果需要持久保存，请通过项目原有的代码或资源编辑流程应用最终数值。

支持 Lua 项目吗？

支持已接入原生 Runtime SDK 的兼容 Cocos2d-x 项目，可检查包括 Lua 创建的实时 Cocos 节点及受支持的组件属性。这不代表支持任意 Lua 变量检查或完整的 Lua 源码调试器。

MCP 集成是什么？

MCP 是 Model Context Protocol（模型上下文协议）。CocosEditor 提供工具，供兼容的 AI 客户端检查和操作已连接的游戏运行时，辅助开发与调试。实际可用工具取决于运行时支持的能力。配置与操作详情请参阅 MCP 接口文档。

目前尚无公开安装包。请通过 email@tonychenn.cn 或 gogle.huiy@gmail.com 联系作者，申请获取编辑器与版本匹配的 Runtime SDK。来信请说明引擎版本、项目语言与目标平台。

CocosEditor 免费吗？

CocosEditor 与 SDK 的使用以各版本附带的许可条款或最终用户许可协议为准，请在使用前查看相应条款。GitHub 仓库用于分发版本和文档，不是编辑器的开源源码仓库。
